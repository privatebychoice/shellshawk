Posts and messages are written in **markdown**. This guide shows each
supported style, rendered the way you will see it. Choose *Try it* from the
menu to preview your own text.

# Emphasis

Write `**bold**` for **bold**, `*italic*` for *italic*, and `~~struck~~` for
~~struck out~~ text. Wrap code in backticks: `ls -l`.

# Headings

Start a line with `#`, `##` or `###` for three heading levels.
Your headings sit under the title of the screen or page they appear on, so
screen readers announce `#` as level 2 (level 3 in a conference post).

# Quotes

> Start a line with `>` to quote someone.
>
> > Add another `>` to quote a quote.

# Lists

1. Number lines for an ordered list.
2. The numbers can start anywhere.

- Start lines with `-` for a bulleted list.
  - Indent two spaces to nest a list.

# Code

```go
// Fence code with three backticks and an optional language.
fmt.Println("hello")
```

# Links

Write `[text](https://example.org)` or paste an address on its own:
https://example.org. Every link shows a privacy grade from A (clean) to F
(invasive), or ? when the site has not been rated, before you visit it.

Only web (https and http) and email links are kept. Images are never
loaded, and HTML is shown as plain text.
