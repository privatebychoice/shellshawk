{{.Site}} is a bulletin board system you use from a terminal over SSH. This website shows part of it once you are logged in.

Connect

{{if .SSHAddress}}

Connect with any SSH client:

ssh -p {{.SSHPort}} YOUR-USERNAME@{{.SSHHost}}
{{else}}

Connect with any SSH client to this server's SSH port. Ask the operator for the address.

{{end}} {{if .HostKey}}

The first time you connect, check that the server's key fingerprint is exactly:

{{.HostKey}}
{{end}}

Join

Membership is by invitation. Ask a member for an invite code, then connect as user {{.InviteUser}} and enter the code as the password. You will create your account and add your SSH key.

Use the website

Log in to the BBS over SSH, open Web login code from the main menu, and enter the code on the login page. Codes work once and expire after five minutes.

The BBS works with screen readers: when you connect, type s to use screen reader mode.
